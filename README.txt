酒鬼地图暖心版 · 南京（地址校对更新版）

上传方法
1. 新建独立GitHub仓库，例如 map4AlcholicsInNJ。
2. 将本目录 index.html 上传至仓库根目录。
3. Settings → Pages → Deploy from a branch → main / (root) → Save。
4. 使用Pages生成的HTTPS链接。微信定位受微信及系统权限影响，也可以输入地点名称搜索。

只需上传index.html。其他文件是原始地址和坐标校对备份。

数据来源及校对
- 已实际读取「酒鬼巡游记」南京26五期小程序适用门店页，61家完整地址及参考营业时间，读取日期2026-11-26。
- 61家均有GCJ-02坐标，可参与距离排序。坐标来自高德，逐一对照小程序门牌号或楼栋园区名称。
- 其中11家仅定位到门牌号、楼栋、园区、街区、路口或商业体附近，页面明确标为约定位；它们不代表精确酒馆入口。详见CSV及JSON中的坐标说明。
- surprise按太平北路136-11号的门牌坐标匹配，高德店名为natural moment，不当作同名商户已确认。
- Myna Bar使用小程序石鼓路阳光大厦20楼位置，纠正上一版王府大街同名店坐标。
- 南京KinK9采用华侨路26号分店；Morpho采用小程序99号附近，不使用高德95号。
- 高德地址编码会出现错误门牌和同名道路，已排除明显不符的结果，例如酒趣返回125号、懒鲸茶南店返回江宁明园路、SU LOUNGE56返回秦淮金鹰村庄。
- 小程序参考营业时间原文展示，包含休息日；始终显示全部，不按营业时间隐藏。
- 未编造评分和活动酒款；没有南京官方路线原图，使用完整门店名单替代上海路线页面。

功能
自动定位、南京地点搜索、直线距离最近5家、逐店高德步行预估、统一起终点步行导航、类型筛选、全部名单搜索、本机打卡和评价。
直线距离用于排序，步行时间不用于排序。到店入口或楼层会影响实际步行时间。
复用此前授权公开使用的高德Key。打卡评价保存在当前浏览器，不能跨设备同步，清除浏览器数据会删除记录。
